# 📡 API Specification

Base URL: `/api/v1`

## Карточки

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/cards` | Список карточек (фильтры: deck, tag, difficulty) |
| `POST` | `/cards` | Создать карточку |
| `GET` | `/cards/:id` | Получить карточку |
| `PUT` | `/cards/:id` | Обновить карточку |
| `DELETE` | `/cards/:id` | Удалить карточку |

## Колоды

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/decks` | Публичные колоды |
| `POST` | `/decks` | Создать колоду |
| `GET` | `/decks/:id` | Получить колоду с карточками |
| `PUT` | `/decks/:id` | Обновить колоду |
| `DELETE` | `/decks/:id` | Удалить колоду |
| `POST` | `/decks/:id/fork` | Скопировать чужую колоду |

## Пользователи

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/auth/register` | Регистрация |
| `POST` | `/auth/login` | Логин (JWT) |
| `GET` | `/users/:id/decks` | Колоды пользователя |

## Сессии изучения

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/sessions` | Начать сессию |
| `PUT` | `/sessions/:id` | Обновить результат |
| `GET` | `/users/:id/stats` | Статистика пользователя |
