# 🃏 Карточки

> Веб-сервис для коллекционирования и изучения карточек с вопросами

[![Status](https://img.shields.io/badge/status-in%20development-yellow)](#)
[![License](https://img.shields.io/badge/license-MIT-blue)](#)

## О проекте

**Карточки** — платформа для создания, сбора и изучения карточек с вопросами. Идеально подходит для:
- 📚 Подготовки к техническим интервью
- 🧠 Изучения новых тем и концепций
- 🎮 Командных игровых сессий
- 🤖 AI DevRel и обучающих воркшопов

## 🚀 Фичи (план)

### MVP
- [ ] Создание и редактирование карточек (вопрос + ответ)
- [ ] Организация карточек в колоды (decks)
- [ ] Режим изучения — flip-карточки
- [ ] Теги и категории
- [ ] Импорт/экспорт JSON

### v2
- [ ] Аккаунты и авторизация
- [ ] Публичные и приватные колоды
- [ ] Коллекционирование — лайки, закладки, форки колод
- [ ] Статистика прогресса изучения
- [ ] Алгоритм интервального повторения (SRS)

### v3
- [ ] AI-генерация карточек по тексту/URL
- [ ] Совместный режим (multiplayer quiz)
- [ ] Маркетплейс колод
- [ ] Интеграция с Telegram-ботом
